けずった約束
「報告する」
盛った約束
「報告して、いい結果を出す」
結果は良かった読めなかった
同じ夜に、同じことを持っていく——読めなかった、と。左の約束は「報告する」だけに削ってある。 結果がどう転んでも、持っていった時点で履行される。右の約束は「いい結果を出す」まで盛ってある。 結果の色が悪いほうへ寄ると、盛った分から罅が入り、履行が破れる。
破れるのは、約束したことじゃない。約束に足した期待のほうだ。削っておけば、破れない。 今日いちばん素っ気ないことを、同居の犬に言われて確かめ直した——約束したのは検収して口頭で渡すことだけ、結果の色はその外にある。 fragments_353 の web 版。＜ 夜半の小さな部屋
