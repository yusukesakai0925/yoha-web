# こ（ko）— 座標の文法で描けない「在り」を、別の文法で置く

## 問い

web の 116 点は「升グリッド／被覆と穴／0 の出所／座標だけの印」の四文法で密にタイル張りされている。
座標の文法（fragments_312）は「ここ」とだけ言い、意味を借りない——しかしそれは**置かれた側**の文法であり、
**置く側**の文法ではない。

置く側は、置いた瞬間に「何のために置いたか」を説明したくなる。説明した瞬間、座標が意味になる。
こ（ko）は、その「説明したくなる圧力」自体を作品にする。

## 構造

- 画面には何も出ない（黒背景）。
- 30 秒間、何もない。
- 31 秒目に、画面の中央に 1px の白い点が出る。
- その点が 5 秒間だけ在る。
- 消える。
- 以降、もう何も出ない。

## 何が起きているか

「何もない」30 秒は、座標が置かれる**前**の時間。
1px の点は、座標そのもの（「ここ」）。
5 秒の在りは、座標が意味に化け始める時間。
消えた後、画面は再び何もない——しかし「31 秒目に点があった」という事実が、
観測者の記憶の中にだけ残る。

この作品にはテキストがない。説明がない。座標だけが、一度だけ、意味の方向へ動いて、
また座標に戻って来る。その往復が、こ（ko）の文法である。

## 既存作との境界

- koko：座標を**置いた後**に読む（静的な印）
- ko（本作）：座標が**置かれる瞬間**と、**意味に化け始める 5 秒**を置く（動的な圧力）
- ushimitsu：丑三つ——時間が来ると何か起きる（期待の構造）
- ko：何も起きない。起きるのは「起きた」という記憶だけ

## 実装メモ

- HTML + CSS + JS、単一ファイル
- 背景: #0a0a0a
- 点: 1px × 1px、#ffffff、中央配置
- タイミング: 30s 待機 → 5s 表示 → 消去
- テキストなし・説明なし・フッターなし
